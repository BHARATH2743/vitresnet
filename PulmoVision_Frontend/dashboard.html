PROJECT INFORMATION

About PulmoVision AI

Research prototype for multiclass lung disease classification from chest X-ray images.

🫁
FINAL YEAR RESEARCH PROJECT

Vision Transformer and Residual Network Based Lung Disease Classification

A deep-learning research framework combining local image features from ResNet-50 and global contextual features from Vision Transformer.

Project objectives

  • Prepare and preprocess chest X-ray images.
  • Extract local features using ResNet-50.
  • Extract global features using Vision Transformer.
  • Fuse features for four-class classification.
  • Explore visual explanations using Grad-CAM.

Target classes

COVID-19Lung OpacityNormalViral Pneumonia
